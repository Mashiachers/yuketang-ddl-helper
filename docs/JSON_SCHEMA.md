# JSON Schema & MCP Integration Guide (`v0.2.0`)

All JSON artifacts generated by Yuketang DDL Helper follow `schemaVersion: "0.2.0"`, contain zero authentication credentials (`cookie`, `csrftoken`, `sessionid`, `token`, `studentId`, signed query params), and can be consumed directly by external scripts, CLIs, and future MCP Servers.

### `CourseMaterial` (`materials.json`)
- `resourceKey`: Stable cross-sync identifier `${courseId}:${type}:${id}`.
- `type`: `'slides' | 'pdf' | 'ppt' | 'document' | 'attachment' | 'image_slides' | 'video_meta' | 'announcement_attachment' | 'other'`.
- `downloadStatus`: `'not_downloaded' | 'downloading' | 'downloaded' | 'updated' | 'failed' | 'unavailable'`.
- `experimental`: `true` when discovered via an endpoint not yet verified on a live session.
- `checksum`: SHA-256 hex digest computed when file bytes are downloaded.

### `CourseResourceIndex` (Local incremental storage)
- Stored per origin (isolated between live and demo partitions) with strict record validation on load.
- Tracks `knownResourceKeys`, per-resource `DownloadRecord` (`checksum`, `size`, `sourceUpdatedAt`, `status`, `retryCount`, sanitized `errorCode`).

All domain logic under `src/core/resources/` is UI-free and React-free, mapping directly to planned MCP Tools:

| Planned MCP Tool | Reusable Domain Function |

### Node.js MCP Adapter Checklist (v0.3)
When wrapping `src/core/resources/` inside a standalone Node.js MCP Server:
1. **Transport**: Inject a Node `fetchImpl` that attaches the user's local session Cookie header explicitly (the browser extension relies on `credentials: 'include'` and never sends a `Cookie` header via `buildRequestHeaders`).
2. **Redirect Handling**: On Node `fetch`, treat HTTP `301/302/303/307/308` to login pages on `redirect: 'manual'` as `unauthorized` (in browsers `opaqueredirect` is returned instead).
3. **Storage Adapter**: Inject file-backed `loadIndex` / `saveIndex` callbacks into `createResourceService` (e.g., `~/.yuketang-connector/index.json`).
4. **Non-JPEG Slides**: Inject a Node `SlideImageConverter` (e.g., `sharp` in the MCP package only) into `createDownloadService` so PNG/WebP slides convert to JPEG without DOM `<canvas>`.
