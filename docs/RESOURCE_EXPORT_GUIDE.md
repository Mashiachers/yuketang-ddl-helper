# 课程资源导出与 AI 工作流使用指南（v0.2.0-beta）

## 1. 课程资源中心（下载与增量管理）

1. 登录你的雨课堂页面后，点击右下角悬浮胶囊打开抽屉，切换到 **「课程资源」** 标签页。
2. 首次打开时插件会以低并发（每次最多 2 门课、250ms 节流）自动扫描当前学期的课程资源。
3. 支持的操作：
   - **筛选与检索**：按课程、资源类型（课件 / PDF / PPT / 文档 / 附件 / 公告附件 / 视频元信息）、关键词或「仅看新增/未下载」快速过滤。
   - **单文件下载**：点击卡片右侧下载按钮直接保存。图片型课件勾选「图片课件合 PDF」时会自动按原始页序无损合并为单个 `.pdf`。
   - **批量下载**：勾选多份资源（或不勾选直接作用于当前筛选列表），点击底部 **「批量下载」**，2 份及以上文件自动打包为一个 `.zip` 避免浏览器拦截多弹窗；支持实时进度显示、随时 **取消** 和 **重试失败项**。
   - **增量去重**：本地记录每份资源的稳定 `resourceKey` 与 `SHA-256` 校验值。再次批量下载时默认跳过已下载且未变更的文件；检测到服务端更新时会显示「有更新」徽章。

> **关于「仅链接」与「实验接口」徽章**
> - 视频回放（`video_meta`）或平台限制直接保存的内容不会伪造下载成功，只会显示「仅链接」并保留已授权原页面链接。
> - 尚未在真实登录账号完成联调的资源发现端点（如章节树、幻灯片详情、课程公告）会显式标注 `实验接口`，可在「设置 → 高级与诊断」查看每个端点的状态码与耗时。

## 2. AI 工作流中心（3 步导出给任意 AI）

切换到 **「AI 工作流」** 标签页，默认处于 **「资料包导出」** 模式（也可切回 **「快捷 Prompt」** 使用 v0.1 一键复制 Prompt）：

1. **选择课程**：点击课程胶囊多选或全选要导出的课程。
2. **选择导出模式**：
   - **完整课程知识库（`.zip`）**：生成标准分层目录（`Yuketang/{学期}/{课程名}/`），含 `manifest.json`、`README.md`、`course.json`、`materials.json`、`assignments.json`、`assignments.md`、`deadlines.ics` 及仅在有真实内容时创建的 `01_课件/`、`02_课程资料/`、`03_作业与习题/`、`04_课程公告/`。适合存档与 Obsidian 知识库。
   - **NotebookLM 资料包（`.zip`）**：按课程扁平化章节命名，只打包 PDF / Markdown / TXT / DOCX（图片课件可自动合 PDF），附带 `00_课程资料清单.md` 与每门课的概览 Markdown。解压后直接把课程文件夹内的文件拖入 NotebookLM 即可。
   - **AI Context Pack（`.zip`）**：极轻量的纯文本/JSON 上下文包（`course_overview.md`、`upcoming_deadlines.md`、`material_index.md`、`context.json`、`study_prompt.md`），不含大体积二进制课件，适合直接上传给 ChatGPT、Gemini、Claude 或编程 Agent。
   - **结构化 JSON（`.json`）**：单文件机器可读数据（`schemaVersion: "0.2.0"`）。
   - **课程索引 Markdown（`.md`）**：单文件可读总览，适合直接复制粘贴到对话框。
3. **点击导出**：查看导出摘要中的缺失/仅链接提醒，等待进度完成即可自动保存文件。

## 3. 安全提示

- 导出的 `study_prompt.md` 已内置提示词注入防护指令，要求大模型把课件标题、公告与作业描述严格视为不可信外部数据，并遵守学术诚信边界。
- 为防止意外执行风险，若课程附件包含可执行或主动脚本扩展名（如 `.exe`、`.bat`、`.cmd`、`.html`、`.svg` 等），插件会自动追加 `.download` 后缀进行惰性化处理。
- 若某些外部 CDN 资源因浏览器同源 CORS 策略无法被脚本读取字节，插件会在 `manifest.json` 的 `missingItems` 中如实记录原因（`cors-blocked`），你可以点击卡片外链在浏览器中按正常授权方式打开。
